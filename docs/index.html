math-stats
GitHub npm

A small JavaScript library that does statistics for your numbers. Mean, median, mode, variance, standard deviation, harmonic and geometric mean — nothing else.

npm install math-stats

Usage

var stats = require('math-stats');

var numbers = [1, 2, 3];
var moreNumbers = [1, 2, 1, 3];

stats.mean(numbers);              // 2
stats.median(numbers);            // 2
stats.mode(moreNumbers);          // [1]
stats.mode(['red','blue','red']); // ['red']
stats.standardDeviation(numbers); // 0.8164965809277260
stats.variance(numbers);          // 0.6666666666666666
stats.harmonicMean(numbers);      // 1.6363636363636365
stats.geometricMean(numbers);     // 1.8171205928321397

Functions

mean(numbers)
Arithmetic mean of an array of numbers.
median(numbers)
Middle value of a sorted array (average of the two middle values for even-length arrays).
mode(values)
Most frequent value(s). Works on numbers or strings.
variance(numbers)
Average of the squared differences from the mean.
standardDeviation(numbers)
Square root of the variance.
harmonicMean(numbers)
Reciprocal of the arithmetic mean of the reciprocals.
geometricMean(numbers)
nth root of the product of n numbers.
